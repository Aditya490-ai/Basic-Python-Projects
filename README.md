🐍 Basic Python Projects

Welcome to my Basic Python Projects repository! 👋

This repository contains beginner-level Python projects that I created to practice and improve my Python programming skills. These projects helped me understand fundamental Python concepts such as variables, conditional statements, loops, dictionaries, lists, user input, and basic application logic.

📌 Projects Included
1. 🤖 Chat Bot

A simple rule-based chatbot that interacts with users through text input.

Features:

Asks the user's name and welcomes them.
Responds to predefined messages.
Recognizes greetings like hello and hye.
Answers basic questions about Python.
Ends the conversation when the user types bye.

Concepts Used:

Variables
Dictionaries
While loops
If-elif-else statements
User input and print statements
2. 📝 To-Do Application

A simple command-line To-Do application that allows users to manage their daily tasks.

Features:

Basic username and password verification.
Add new tasks.
View all added tasks.
Delete existing tasks.
Exit the application.

Concepts Used:

Lists
Loops
Conditional statements
User input
List methods (append(), remove())
3. 💰 Expense Tracker

A basic expense management application that allows users to record and view their expenses.

Features:

Add expenses with date, category, and price.
View all recorded expenses.
Calculate total expenses.
Exit the application.

Concepts Used:

Lists and dictionaries
While loops
Conditional statements
For loops
Basic arithmetic operations

🚀 How to Run These Projects
Clone this repository:
bash
git clone https://github.com/Aditya490-ai/Basic-Python-Projects.git

Open the project folder.
Install Jupyter Notebook if you don't have it:
bash
pip install notebook

Launch Jupyter Notebook:
bash
jupyter notebook

Open basic_python_projects.ipynb.
Run the cells one by one to explore and use the projects.
